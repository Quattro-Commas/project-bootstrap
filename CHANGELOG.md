# Changelog

## [1.0.0] - 2026-10-15

### Added
- `bootstrap` skill that auto-orients sessions by classifying the current directory.
- `/project-bootstrap:resume` command to re-orient on an existing repo and refresh `.kimi-code/PROJECT.md`.
- `/project-bootstrap:newproject` command to scope and scaffold a new project.
- `/project-bootstrap:wrapup` command to update `PROJECT.md` status, decisions, and next steps.
- Monetization planning skills: `monetization-strategy`, `plugin-go-to-market`, `plugin-pricing`.
- `README.md` with install instructions, quick-start, privacy note, and Pro waitlist link.
- `SECURITY.md`, `AGENTS.md`, `.kimi-code/PROJECT.md`, issue/PR templates, and MIT `LICENSE`.
- `MONETIZATION.md`, `HOSTED-SERVICE-MVP.md`, and `LAUNCH-EXPERIMENT.md` for the public launch.
